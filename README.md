# RSI Strategy Backtest on Top 10 Active Stocks

This repository contains a Python notebook that backtests a popular **RSI trading strategy** on the top 10 most active stocks over the past five years. 

The notebook demonstrates:

- Downloading historical stock data  
- Calculating the Relative Strength Index (RSI)  
- Generating realistic buy and sell trades with stateful logic  
- Building a portfolio and calculating cumulative returns  
- Visualizing trade points, equity curves, and performance metrics  

The project highlights how the RSI strategy behaves compared to a simple buy-and-hold approach and shows the importance of realistic backtesting for trading strategies.
